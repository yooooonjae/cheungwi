## Global Constraints

- 저장 형식은 JSON 단일. SQLite·CSV·pandas 금지(수집기는 표준 라이브러리만).
- 금액은 **원**, 면적은 **㎡**, 날짜는 `YYYY-MM-DD`(일 단위)·`YYYY-MM`(월)·`YYYYQn`(분기) 문자열.
- 모든 API 응답 원본은 `data/raw/{source}/`에 캐시하고, 캐시가 있으면 API를 호출하지 않는다. 오류 응답은 캐시하지 않는다.
- 오류를 삼키지 않는다: `api_get`은 예외를 `(status, text)`로 환원하고, 수집기는 실패를 stdout과 산출물 meta에 남긴다.
- 쿼터 소진은 정상 종료 사유다: 진행 파일을 저장하고 exit 0. 단, stdout 마지막 줄에 `RESUME_NEEDED` 또는 `COMPLETE` 마커를 출력한다(시차 rent.py의 "완주·소진 구분 불가" 함정 보완).
- 산출 JSON에는 반드시 `meta`(수집일 `collected_at`, 출처, 가정, 제외 내역)를 넣는다. 추정·제외는 숨기지 않고 meta에 기록한다.
- DB-write 물리 게이트: 게이트 위반 행은 기록 자체를 막는 게 아니라 `flags`/`excluded`에 사유와 함께 격리한다.
- 커밋 메시지는 완결된 한국어 문장, Claude 트레일러 금지. 작업(Task) 단위로 커밋 후 `git push`.
- config.json은 gitignore 유지. 키 이름: `service_key`(data.go.kr) · `rone_key` · `vworld_key` · `ecos_key` · `dart_key`.
- 테스트는 pytest, 루트 `conftest.py`(주석만)로 `src.*` 임포트. 수집기 테스트는 fixture 기반(라이브 API 금지), 라이브 확인은 별도 "스모크 1셀" 스텝으로만.

```python
def call_with_backoff(fn, tries=5, base_sleep=2.0):
    """fn() -> (status, text) 를 최대 tries회 시도. 5xx·-1(네트워크)만 백오프 재시도.

    기존 시리즈에서 rone/rtms/archub가 각자 구현하던 루프의 공통화.
    4xx는 즉시 반환한다(키·파라미터 문제는 재시도해도 소용없다).
    """
    status, text = -1, ""
    for attempt in range(tries):
        status, text = fn()
        if status == 200:
            return status, text
        if 400 <= status < 500:
            return status, text
        time.sleep(base_sleep * (attempt + 1))
    return status, text
```
