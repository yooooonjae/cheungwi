**Goal:** out/*.json 4종을 「층위」의 조형 언어(단면·지층·수면)로 렌더링하는 정적 SPA를 만들고, JS 패리티 실험실·자동 갱신 파이프라인·cheungwi.pages.dev 배포까지 완성한다.

## Global Constraints

- 사이트는 **완전 정적·외부 요청 0**: CDN·웹폰트·외부 이미지 금지. 데이터는 빌드타임에 `web/data/*.js`(`window.__DATA_*`)로 굽는다(수지 dist 방식).
- **정직성 원칙(스펙 §9)**: 임대료가 권역 지표+보정 추정임을 UI에 명시, pending_ledger 55동을 숨기지 않고 표시, implausible 신호·gate_violations는 화면에 사유와 함께 노출. LLCR은 두 값 함께.
- 시각 언어: 단면(section)·지층(strata)·수면(waterline). 색·타이포·간격은 토큰(css 변수) 단일 출처. 라이트·다크 모두 지원.
- JS 패리티: 핸드오프 문서의 9함수(effective_rent·building_adjust·noi·appraise·implied·max_loan·hold_model·refi_test·breakeven_vacancy)를 `site/js/engine.js`로 미러링, Python↔JS 무작위 대조(rel 1e-9, `random.seed(42)`) + 골든 재검(수지 test_parity 패턴).
- 반응형: 390px~1440px, 가로 오버플로 0, 터치 타깃 ≥44px(수지 responsive_check.js 계승). **헤드리스 390px 클램프 함정 주의**(뷰포트 강제 클램프 — 개발 리포 이력 참조).
- 한국어 조사 분리 검사·미치환 플레이스홀더 검사 게이트(수지 assemble 계승). noindex 기본.
- 커밋 메시지 완결된 한국어 문장·트레일러 금지, 태스크 단위 커밋+push. `make test` 전체 그린 유지(346+).
